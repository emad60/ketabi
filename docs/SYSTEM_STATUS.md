## 📊 الميزات الرئيسية

### إدارة المخازن
- عرض جميع مخازن الوزارة/المحافظة
- إضافة مخازن جديدة
- البحث والفلترة
- إدارة الموظفين

### إدارة المخزون
- عرض جميع الكتب في المخزن
- إضافة كتب جديدة
- تعديل الكميات (+100 / -100)
- تنبيهات المخزون المنخفض
- البحث والفلترة
- تتبع حركة المخزون

### إدارة الشحنات
- إنشاء شحنات جديدة
- تعيين المندوبين
- تتبع حالة الشحنة
- QR Code لكل شحنة
- فلترة حسب الحالة
- عرض محتويات الشحنة

## 👥 المستخدمين التجريبيين

### مستخدم الوزارة
```
Username: ministry_admin
Password: Admin@123
Role: ministry_staff
```

### مستخدم المحافظة
```
Username: province_admin  
Password: Admin@123
Role: province_staff
Province: أمانة العاصمة
```

## 🌐 الروابط

- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8000/api
- **Admin Panel**: http://localhost:8000/admin

## 🗺️ المسارات (Routes)

### الوزارة
- `/ministry/dashboard` - لوحة التحكم الرئيسية
- `/ministry/warehouses` - إدارة المخازن
- `/ministry/warehouse/:id/stock` - إدارة مخزون مخزن محدد
- `/ministry/shipments` - إدارة الشحنات

### المحافظة
- `/province/dashboard` - لوحة التحكم الرئيسية
- `/province/warehouse/:id/stock` - إدارة المخزون
- `/province/shipments` - الشحنات الواردة

## 📦 البيانات التجريبية

### المخازن
- **المخزن المركزي - صنعاء** (وزارة)
- **مخزن أمانة العاصمة الرئيسي** (محافظة)

### الكتب
- كتاب الرياضيات - الصف الأول (500 نسخة)
- كتاب اللغة العربية - الصف الثاني (300 نسخة)
- كتاب العلوم - الصف الثالث (25 نسخة - منخفض)

## 🚀 البدء

1. تسجيل الدخول على http://localhost:3000
2. استخدم أحد المستخدمين التجريبيين
3. ستُحوّل تلقائياً إلى Dashboard المناسب
4. جرّب الميزات المختلفة!
