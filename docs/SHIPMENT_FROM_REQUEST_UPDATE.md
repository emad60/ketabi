## 🔄 سير العمل الجديد

### رحلة الموافقة والشحن:

1. **المحافظة تنشئ طلباً** 📋
   - تحديد الكتب والكميات المطلوبة
   - إرسال للوزارة

2. **الوزارة تراجع الطلب** 👀
   - عرض تفاصيل الطلب
   - فحص المخزون لكل كتاب
   - تعديل الكميات الموافق عليها

3. **الموافقة على الطلب** ✅
   - تحديث حالة الطلب
   - حفظ الكميات الموافق عليها

4. **إنشاء الشحنة (جديد!)** 📦
   - **فوري**: سؤال "هل تريد إنشاء شحنة الآن؟"
   - **تلقائي**: تعبئة بيانات الشحنة من الطلب
   - **سهل**: اختيار مستودع الوزارة فقط
   - **دقيق**: ربط الشحنة بالطلب

5. **تتبع الشحنة** 🚚
   - الشحنة مربوطة بالطلب
   - يمكن تتبع حالتها
   - إشعارات تلقائية
