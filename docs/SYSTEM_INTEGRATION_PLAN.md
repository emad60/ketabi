# خطة التكامل الشاملة لنظام كتابي

## 📊 الحالة الحالية (Current State)

### ✅ ما هو موجود في Backend:

#### Models:
1. **BookRequest** - طلبات المحافظات للوزارة
   - الحالات: pending, approved, rejected, fulfilled
   - تشمل: BookRequestItem (تفاصيل الكتب)
   
2. **SchoolRequest** - طلبات المدارس للمحافظة
   - الحالات: draft, submitted, approved, rejected, fulfilled, cancelled
   - تشمل: SchoolRequestItem (تفاصيل الكتب)

3. **Shipment** - الشحنات
   - من وزارة → محافظة (from_ministry → to_province)
   - من محافظة → مدرسة (to_school_name)
   - الحالات: pending, assigned, out_for_delivery, delivered, confirmed, canceled
   - يشمل: QR Code, GPS tracking, proof of delivery

4. **WarehouseStock** - المخزون
   - مخازن الوزارة والمحافظات
   - تتبع الكميات لكل كتاب
   - StockMovement - سجل حركة المخزون

5. **Users, Books, Schools, Provinces** - البيانات الأساسية

## 📋 السيناريو الكامل المطلوب

### 1. المدرسة تطلب كتب
```
المدرسة → إنشاء SchoolRequest → إرسال للمحافظة
```

### 2. المحافظة تراجع وتجمع
```
المحافظة → مراجعة SchoolRequest → قبول/رفض
المحافظة → تجميع طلبات متعددة → إنشاء BookRequest للوزارة
```

### 3. الوزارة تراجع وتوافق
```
الوزارة → مراجعة BookRequest → التحقق من المخزون
الوزارة → قبول/رفض → إنشاء Shipment تلقائياً
```

### 4. الشحن للمحافظة
```
الوزارة → تجهيز الشحنة → تعيين مندوب
المندوب → توصيل → تحديث GPS
المحافظة → استلام → مسح QR Code → تحديث المخزون
```

### 5. التوزيع للمدارس
```
المحافظة → إنشاء شحنات للمدارس → تعيين مندوبين
المندوب → توصيل للمدرسة
المدرسة → استلام → تأكيد
```
