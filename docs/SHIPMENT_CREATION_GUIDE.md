- ⭕ **مدرسة** (لإرسال شحنة مباشرة لمدرسة)

**مثال:** اختر "مدرسة"

#### ج) **اختر الوجهة:**
```

```


الخيارات:
- `ministry_courier`: مندوب الوزارة
- `province_courier`: مندوب المحافظة
- `government_transport`: النقل الحكومي
- `private_courier`: شركة خاصة


## 🎯 الخطوات التالية بعد الإنشاء

### 1. **تعيين مندوب:**
```

المندوب: يتم اختياره من قائمة المندوبين
```

### 2. **بدء التوصيل:**
```
الحالة: assigned → out_for_delivery
يتم تفعيل: GPS Tracking
```

### 3. **إتمام التسليم:**
```
الحالة: out_for_delivery → delivered
مطلوب:
  - صورة إثبات التسليم
  - التوقيع الرقمي
  - اسم المستلم
```

### 4. **التأكيد النهائي:**
```

النتيجة: يتم خصم الكميات من المخزون
```
